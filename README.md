Tukios Obit Only Plugin for WordPress

Added a location filter to the listings widget. To use it, add the location ID and a label for each location to the [tukios_obituaries_listings] shortcode.

For example:

[tukios_obituaries_listings locations=853750:Tukios1,968255:Tukios2]
